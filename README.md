## 🚀 Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/brokenspagheti/network-state-research)

### Manual Deployment Steps:

1. Go to [Vercel](https://vercel.com)
2. Sign in with your GitHub account
3. Click "Add New Project"
4. Import this repository: `brokenspagheti/network-state-research`
5. Click "Deploy"

That's it! Your site will be live in seconds.
